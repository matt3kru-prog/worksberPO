# PO Knowledge Base — Platform V Works Architect

Рабочая база знаний Product Owner. Она хранит факты, решения, договорённости, гипотезы и открытые вопросы — чтобы их можно было быстро использовать при подготовке встреч, приоритизации, аргументации и планировании.

## Правила ведения

- Разделять **факты**, **интерпретации** и **непроверенные сигналы**.
- Для значимых решений фиксировать контекст, альтернативы, автора решения, дату, последствия и следующий шаг.
- В разделе организационной динамики описывать наблюдаемые интересы и влияние, без приписывания людям мотивов как установленного факта.
